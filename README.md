# TicTacToe

A simple console-based TicTacToe game in Python. Play against the computer in the terminal.

## Features

* 3x3 grid
* Player vs Computer
* Input validation to prevent invalid moves
* Detects winning combinations and announces the winner

## How to Play

1. Run `main.py`
2. Enter a number between 1-9 to place your X
3. Computer plays O automatically
4. First to align 3 marks horizontally, vertically, or diagonally wins

## Requirements

* Python 3.x
